# Meu ambiente de desenvolvimento

Uso o **VS Code** no dia a dia e, quando estou fora de casa, abro o *Codespaces* no navegador.

## Extensões que uso

- Vitest (rodar testes)
- Live Server (ver o site enquanto edito)
- GitLens (histórico do Git)

## Como preparar um computador novo

1. Instalar o Node.js LTS.
2. Instalar o Git e configurar nome e e-mail.
3. Clonar o repositório e rodar `npm install` na pasta.

```bash
git clone https://github.com/usuario/study-to-work.git
cd study-to-work
npm install
```

Documentação do Node: [nodejs.org](https://nodejs.org/pt)

| Atalho       | O que faz                 |
| ------------ | ------------------------- |
| Ctrl+P       | Abre um arquivo pelo nome |
| Ctrl+Shift+P | Abre a paleta de comandos |

> Programar é 10% escrever código e 90% entender por que ele não funciona.
