# Projeto 00 — README de perfil do GitHub

## O problema

Recrutadores e clientes olham o seu GitHub **antes** de falar com você. Um perfil vazio
passa a impressão de alguém que não pratica. O GitHub tem um recurso pouco conhecido:
se você criar um repositório **com o mesmo nome do seu usuário**, o `README.md` dele
aparece no topo do seu perfil, como uma página de apresentação.

Ao longo do curso, este README vai ser atualizado a cada projeto novo. Ele é a sua vitrine.

## Requisitos

1. Criar no GitHub o repositório `seu-usuario/seu-usuario`, **público**.
2. Clonar o repositório e escrever o `README.md` com:
   - título com saudação e seu nome;
   - seção **Sobre mim** (quem você é, de onde vem, o que te trouxe à programação);
   - seção **Tecnologias** (o que você já estuda; seja honesto, pode ser só HTML, CSS e Git agora);
   - seção **Estudando agora** ou **Objetivos**;
   - seção **Contato** com link para o LinkedIn e/ou e-mail (`mailto:`).
3. Imagens (se usar) **com texto alternativo**.
4. Nada de texto de exemplo esquecido ("lorem ipsum", "seu nome aqui", "TODO").
5. Commits no padrão Conventional Commits e `git push` para o GitHub.

## Para ir além (opcional)

- Badges com as tecnologias (pesquise "shields.io"), sempre com alt.
- Uma frase sobre o que você busca: vaga júnior, estágio, freelas.

## Correção

Na raiz do curso, aponte para a pasta onde você clonou o repositório de perfil:

```bash
npm run corrigir-projeto -- 00 ../seu-usuario
```

## O que falar na entrevista

"Montei meu perfil como uma página de apresentação e atualizo a cada projeto. Lá estão
as tecnologias que domino e o link para cada projeto, com o deploy."
